## 4 - Построение прогнозной модели

* Целевая переменная — факт попадания займа на торги. Активные займы с неизвестным исходом не используются при формировании обучающей выборки
* Доступны данные о количестве текущих займов, о прошлых займах и их итогах, ценности, уплаченных процентах и тд
* Признаки для каждого займа должны рассчитываться только на основании информации, доступной на момент его выдачи, чтобы исключить утечку будущей информации (исходя из этого, обучение на более ранних данных, тестирование на более поздних для предотвращения утечки целевой переменной)
* Бейзлайн - историческая доля займов, ушедших на торги
* Метрика для валидации корректности Вероятностей - Brier score, так как в задании требуется не только корректность предсказаний, но и корректность вероятностей. Также строим и считаем pr-auc
* Итоговую модель c выбранным уровнем порога тестируем по  precision, recall (упор на recall при метке 1 - уйдет на торг) и f1 . Приоритет recall, остальные метрики дополнительные
* Модели будут построены в виде logistic regression и gradient boosting (catboost), т к дают хорошую точность на поставленных задачах, также catboost хорош при работе с категориальными признаками и производителен - скорее всего покажет лучшую метрику
* Модель также необходимо откалибровать, для того чтобы выданные моделью вероятности соответствовали  реальному количеству случаев, попавших на торги
